# Lore adr

Read `../../references/codex-runtime.md`, resolve the knowledge paths, then follow
`../../commands/adr.md`. Treat the user's words as the command argument: a title
means a new record, `list`, `accept NNNN`, `supersede NNNN <title>`, and `discover`
select the other modes, and no argument lists existing records.
