# Lore adr

Read `../../references/codex-runtime.md`, resolve the knowledge paths, then follow
`../../commands/adr.md`. Treat the user's words as the command argument: a title
means a new record; `list`, `index`, `accept`, `reject`, `observe`, `supersede`,
`deprecate`, `move`, `retire`, `lint`, and `discover` select the other modes; no
argument lists existing records.
